## 1. v1 保留什么（不推翻）

- Thesis → Edge → Signal → Prediction → Position 的分层框架。
- Tier 四档（Explore/Watch/Verify/Core）及证据成熟度授权逻辑。
- 现金 ≥10% 为唯一仓位硬约束；单基金 15% / 单板块 20% / 主题集群 30% 为参考线（v1.1）。
- Trend Gate（MA20<MA60 默认禁止买入，作为风险过滤器而非绝对规则）。
- Price–Fundamental Divergence 六类矩阵（①~⑥），Thesis 证伪 = 无条件 Exit。
- 验证闭环：Tier-1（≥90 天）/ Tier-2（30 天），回答「我为什么错了」。
- 节奏：Daily 发现分类、Weekly 摘要、Monthly 决策、Event 例外。

## 3. 新增什么（Market Regime / Risk Budget / Asset-Theme State / Tactical）

目标架构（仅候选，不实现）：

```text
Thesis → Core Position
        → Theme State（每主题自身波动率分位 + 趋势/广度）
        → Theme Risk Budget（主题级暴露阶梯）
        → Tactical Adjustment（最短持有约束）
        → Target Position → Portfolio Constraints → Human Confirm
```

关键结论：**Risk Budget 作用在「主题级」，不是「全局级」**。

- 每个持仓主题，用其代理 ETF 的 20 日波动率 252 日分位 → 决定该主题暴露档位。
- 暴露阶梯（候选）：分位 <50 → 100%，50-75 → 85%，75-90 → 70%，≥90 → 50%。
- 最短持有 30 天：既压低换手，又保证 C 类赎回费 = 0%。

## 6. 每个规则的失败场景

- **趋势牛市**：波动率分位高时降暴露会踏空（2024/2025 少赚 5-10pp），这是「保险成本」。
- **单次波动率脉冲**：某日暴跌拉高 20 日波动率，可能过早降档、之后快速修复（whip-saw）。
- **主题级崩溃**：主题自身波动率未及分位但基本面证伪，仍需靠 ⑥ Thesis Exit，而非预算层。
- **代理 ETF 失真**：ETF 与真实基金净值有跟踪差，主题暴露档位可能略偏。

## 8. 当前仍未知的问题

- 样本仅 2023-01→2026-09（一段上涨 + 一次回撤），未经历深度熊市（2022 式）。
- 用代理 ETF 篮子，非真实基金逐笔净值。
- 波动率分位 50/75/90、暴露 100/85/70/50 是格点假设，无统计最优证明。
- 主题级 vs 全局级的「复杂度溢价」未在真实持仓上验证。
- 用户新手期真实交易的「反事实」交叉验证尚未量化完成（仅定性结论：追高/踢利润是主要失分）。

## 10. 是否建议正式冻结 v2

**不建议现在冻结。** 理由：

1. 样本仅 3.6 年、单一周期，walk-forward 只覆盖 21 个月，未经历深熊。
2. 波动率分位与暴露阶梯仍是格点假设，非实证最优。
3. 用代理 ETF 而非真实基金逐笔净值。
4. 用户新手期真实数据只做了定性交叉验证，反事实量化未完成。

建议：本提案作为 **Candidate Rulebook v2-draft** 存档，继续积累数据（至少再过一个完整周期 /
一次深度回调），并完成反事实交叉验证后，再决定是否冻结。
