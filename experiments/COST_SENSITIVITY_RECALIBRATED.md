# 成本敏感性复算（用校准后的真实台账 + FIFO 费用）

> 输入：E08 校准台账（experiments/ledger/）+ E04/E05/E07 回测结果。
> 目的：用真实交易成本，检验 E04/E05/E07 的「主题级 Risk Budget」优势是否在真实费用下仍成立。

## 1. 真实成本（来自校准台账）

| 指标 | 值 |
|---|---|
| 买入总额 | ¥128,494（126 笔） |
| 卖出总额 | ¥58,067（31 笔） |
| FIFO 赎回费 | **¥161.63** |
| **实际卖出费率** | **0.278%**（161.63 / 58,067） |
| 年化卖出换手 | ≈ 208%（约 5.5 个月 95%） |
| 月费用分布 | 5月 23.84 / 6月 35.45 / 7月 50.63 / 8月 45.81 / 9月 5.89 |

关键：实际费率 **0.278%** 落在 C 类 0%/0.5%/1.5% 三档之间，且显著低于回测里的 0.5% 情景，
更远低于 1.5% 情景。

## 2. 最强候选（THEME_VOL + 30 天最短持有）在真实费率下的表现

## 3. 更重要的修正：30 天持有策略的真实费率是 0%

「THEME_VOL + 30 天最短持有」的每次卖出都满足「持有 ≥30 天」，而 C 类基金 ≥30 天赎回费 = **0%**。

因此回测里给它套的 0.5%/1.5% 是**过度保守**：该策略的真实结果应取 **0% 列
（+84.99%，Calmar 0.90）**，而非 0.5% 列（+81.71%，Calmar 0.86）。

用户自己的实际费率 0.278% 之所以高于 0%，是因为存在 <30 天的短线卖出（「踢利润」「搏反弹」
等），而这正是策略要避免的行为。

## 4. 结论（KEEP / CANDIDATE / REJECT 更新）

- `VALIDATED（加强）`：主题级波动率预算 + 30 天最短持有，在**真实费用下**优势更强
  （真实 Calmar ≈ 0.88–0.90，对照满仓 0.66）。回测的 0.5%/1.5% 情景是下界，不是上界。
- `OBSERVED`：全局 Regime 降暴露（GLOBAL_DISC 等）在真实费率下仍跑输满仓/恒定 80%，
  与 E04/E05 结论一致，不受费用修正影响。
- `UNKNOWN`：上述仍为 2023-01→2026-09 样本内 + 代理 ETF 篮子；真实持仓费用应逐笔 FIFO
  精确复算（E08 已给出 ¥161.63 的近似下界）。

## 5. 一句话

真实交易成本（0.278%，且 30 天持有策略实际为 0%）**没有削弱、反而加强了** E04/E05/E07 的结论：
主题级波动率预算 + 最短持有是当前最强候选；全局一刀切降暴露仍应排除。
