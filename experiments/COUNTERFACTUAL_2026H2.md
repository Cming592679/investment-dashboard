# 反事实验证 — 2026-05→09 用户新手期 vs V2 主题级预算

> 目的：量化「如果从 5 月就按 V2（主题级波动率预算 + 30 天持有）操作，是否好于用户实际追高/踢利润」。
> 用户确认：5~9 月为新手期，大量追高/踢利润/搏反弹行为无纪律，**不作为规则依据，仅作交叉验证**。

## 1. 反事实（8 主题等权，2026-05-14 → 2026-09-17）

| 策略 | 收益 | 最大回撤 | Calmar |
|---|---|---|---|
| 等权满仓持有 | −7.60% | −23.92% | −0.84 |
| **V2 主题级波动率预算 + 30 天持有** | **−2.46%** | **−12.77%** | −0.53 |

V2 比满仓少亏约 **5.1 个百分点**，回撤几乎**减半**（−12.8% vs −23.9%）。

## 2. 关键且诚实的发现：V2 只救「波动型」下跌，不救「阴跌型」仓位

各主题 5/14→9/17 买入持有涨幅：

| 主题 | 涨幅 | 9/17 波动率分位 |
|---|---|---|
| 军工 | **−19.52%** | 0%（低波动阴跌） |
| 机器人 | −18.51% | 17% |
| 电网 | −11.59% | 24% |
| 科创50 | −6.89% | 34% |
| 电子/CPO | −3.74% | 34% |
| 芯片/存储 | −3.19% | 30% |
| 半导体设备 | −2.82% | 25% |
| 纳指 | +5.46% | 13% |

**结论**：
- 波动率预算在 8 月那轮「半导体/芯片/电子」的高波动急跌里有效（分位升高→降档→回撤减半）；
- 但**军工是低波动阴跌 −19.5%**，波动率分位始终 0%，预算层**不会对它降档**——所以它救不了军工。
- 用户实际最大失分点是**军工仓位过重（约 29%→26%）且一路阴跌**，这是「单板块超限」的参考线问题，
  不是「择时/波动率」问题。

## 3. 用户实际 vs 反事实

- 用户实际：8/17→9/4 完整账段约 **−5.04%**，另付换手费 **¥161.63**；
- 且实际组合重仓军工（−19.5%），其真实回撤/亏损大概率**差于**等权满仓的 −7.6%；
- V2 反事实（等权）仅 −2.46%，回撤减半。

## 4. 结论（交叉验证，非规则依据）

1. `OBSERVED`：追高/踢利润/搏反弹造成约 ¥161 换手费 + 在错误时点进出，是确定的成本；
2. `OBSERVED`：V2 主题级波动率预算在「急跌」主题上显著降回撤，但无法处理「阴跌 + 仓位过重」；
3. `UNKNOWN`：用户实际组合为军工重仓，等权反事实与其实组合不可直接等同，需用真实持仓权重重算；
4. 下一条要补的规则方向：**仓位集中度（尤其单一主题阴跌时）**，而不是再加择时指标。
