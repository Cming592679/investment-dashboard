# Investment Dashboard — 基金投资板块监测仪表盘

基于**供应链瓶颈逆向映射框架**的基金监测系统。通过拆解每个投资板块的产业链、定位真瓶颈、追踪领先指标来做**可验证的预判**。

**核心理念**：当你能判断"瓶颈在收紧还是缓解"，就比看价格的人早了 3-12 个月。

---

## 分析体系

### 叠层信号架构（L1-L4）

```
L1 · 技术面 (权重1.0)     RSI / MACD / KDJ / MA50 / Bollinger / 量价关系
L2 · 瓶颈面 (权重2.0)     领先指标趋势 / 瓶颈破坏条件 / 联动降级
L3 · 周期面 (权重1.5)     周期阶段(early/mid/late) + 风险评估
L4 · 事件面 (权重1.0)     财报/发布会结果解析(超预期/不及预期)
```

### 决策树判定（替代线性评分）

不再用简单的加权分数，而是走 8 分支决策树。判定结论包括：
- 🟢 安心持有 / 关注加仓 / 关注反弹
- 🟡 忍着不动 / 超卖观望
- 🔴 考虑跑路 / 高位警惕

量能分支：放量反弹+M金叉 → 反转升格；缩量反弹 → 死猫跳警告。

### 数据健康

- 自动检测领先指标是否过期（按更新周期分级：日度/月度/季度）
- 交叉比对公司财报日历，发现遗漏的关键事件
- 14 天内过期事件提示补充分析结果

### 预测 + 双轨验证

- **Tier-1 指标层**（季度验证）：预测的指标趋势 vs 实际公布数据
- **Tier-2 价格层**（30天验证）：方向+强度判定（✅/➡️/❌）

### 自动化流程

| 时间 | 动作 |
|------|------|
| 盘中 | yfinance 实时拉取股票数据 + 成交量 |
| 18:00 | 全量刷新股票快照 + 保存当日快照 → history/ |
| 20:00 | 新浪API拉取收盘净值 + 份额×净值更新持仓金额 + 保存持仓历史 |

## 设计原则

1. **领先于价格，不追随价格**：指标选的是"还没反映在股价里"的变量
2. **可验证、可证伪**：每个预测有明确验证日和方向
3. **基金视角，不是股票视角**：日涨跌大幅降权，关注中期趋势
4. **瓶颈驱动，不是情绪驱动**：每个指标可追溯到产业链瓶颈点
5. **量价配合验证**：缩量反弹=死猫跳，放量反弹+金叉=反转
6. **份额驱动净值**：shares 为源头真相，amount = shares × nav

## 当前局限性

- 领先指标需手动更新（盯财报/发布会后修改 config.py）
- 北向资金、两市成交额、融资融券余额等 A 股特有指标尚未接入
- 基本面估值（PE/PB/ROE）体系缺失
- 宏观数据层（PMI/社融/LPR/CNY）缺失
- yfinance 对 A 股数据偶有 fetch 失败
