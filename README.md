# Investment Dashboard — 基金投资板块监测仪表盘

一个基于 **Serenity 供应链瓶颈逆向映射框架** 的基金监测系统。不追涨跌、不看 K 线，而是通过拆解每个投资板块的产业链、定位真瓶颈、追踪领先指标来做**可验证的预判**。

**核心理念**：当你能判断"瓶颈在收紧还是缓解"，就比看价格的人早了 3-12 个月。

## 分析框架：从瓶颈到预判

### 不是看价格，是拆产业链

传统方式：盯股价 → 跌了就跑 → 永远慢一步。

这套系统的做法：

```
1. 产业链 5 层逆向拆解
   下游需求 → 中游系统 → 中游器件 → 上游设备 → 上游材料

2. 对每层套 9 大瓶颈原型（Serenity 框架）
   ①材料垄断 ②单源卡脖子 ③产能售罄 ④BOM普适
   ⑤估值套利 ⑥设备瓶颈 ⑦前机构 ⑧巨头依赖 ⑨宏观错杀

3. 从瓶颈反问 → 推导领先指标
   "如果这个瓶颈在收紧，我该看什么数据？"
   "如果这个瓶颈在缓解，什么数值会先变化？"

4. 追踪指标趋势 → 生成预判 + 可验证的预测
```

### 以半导体设备为例

```
产业链拆解：
  Layer 5  下游  MSFT/AMZN/GOOGL AI CapEx
  Layer 4  中游  NVDA GPU → TSMC 代工
  Layer 3  器件  CoWoS 先进封装 ← ⚡ 瓶颈！
  Layer 2  设备  ASML EUV / AMAT / LRCX ← 你的基金在这里
  Layer 1  材料  硅片 / 光刻胶 / 特气

瓶颈识别：
  ② ASML EUV：全球唯一供应商，交期 18 月+
  ② CoWoS：TSMC 独占，NVDA 卡在这里
  ② HBM：SK 海力士/三星/美光三寡头

瓶颈 → 指标推导：
  - EUV 瓶颈在收紧还是缓解？→ 盯 ASML 季度订单
  - CoWoS 在扩产还是停滞？→ 盯 TSMC 月度营收 + CapEx
  - 存储需求在加速还是减速？→ 盯 DRAM 合约价 QoQ
  - AI 投资在继续还是收缩？→ 盯四大云厂 CapEx 指引
```

### 综合研判评分公式

```
综合评分 (0-10) = 领先指标(0-5) + 周期位置(0-2) + 技术面(0-3)

🟢 ≥6 分 → 安心持有（可加仓）
🟡 3-5分 → 忍着不动（多看少动）
🔴 0-2分 → 考虑跑路（反弹减仓）
```

**关键设计决策**：日涨跌幅大幅降权。基金无法盘中交易，单日波动是噪音，不作为跑路依据。LRCX 一天跌 10% → 只记录不扣分。

### 数据流

```
yfinance API
    ↓ (每日 14:00 自动 / 手动 🔄)
data_fetcher.py → 股价 / RSI / MA50
    ↓
app.py → compute_assessment() → 综合评分 + 研判结论
    ↓
/api/fund/<id> → JSON
    ↓
index.html → 三栏面板渲染
    ↓ (同时)
history/*.json ← 快照存档
predictions/*.json ← 预测存档
```

### 前端状态管理

- 页面加载 → 并行请求全部 7 个板块（约 30 秒）→ 缓存到服务端
- 后续访问 → 缓存命中，1-2 毫秒返回
- 标签页圆点 → 实时反映各板块研判状态（🟢🟡🔴）
- 🔄 按钮 → 手动触发全量刷新 + 存快照
- 每日 14:00 → 自动刷新 + 存快照 + 生成预测
- 每周一 10:00 → 自动生成复盘报告

## API 文档

| 端点 | 方法 | 说明 |
|------|------|------|
| `/api/funds` | GET | 列出所有板块 |

## 如何新增一个板块

1. **`config.py`** — 在 `FUNDS` 中添加入口（股票/指数/特殊标的）
2. **`config.py`** — 在 `LEADING_INDICATORS` 中添加瓶颈→指标（用 Serenity 框架拆链后推导）
3. **`config.py`** — 在 `KEY_DATES` 中添加关键事件
4. **`config.py`** — 在 `CYCLE_ASSESSMENTS` 中添加周期判断
5. 重启 Flask，新标签页自动出现

## 验证闭环

```
每日 14:00 快照
    ↓ 含预测（方向 + 验证日）
7 天后验证日
    ↓ 对比预测 vs 实际走势
每周一复盘
    ↓ 统计准确率 / 偏差分析
优化阈值
    ↓ 更新指标 / 调整权重 / 新增信号因子
```

## 设计原则

1. **领先于价格，不追随价格**：指标选的是"还没反映在股价里"的变量
2. **可验证、可证伪**：每个预测有明确验证日和方向，不是模糊的"可能涨也可能跌"
3. **基金视角，不是股票视角**：日涨跌大幅降权，关注中期趋势而非日内波动
4. **瓶颈驱动，不是情绪驱动**：每个指标都能追溯到产业链的具体瓶颈点
5. **诚实标注不确定性**：置信度低就是低，不装懂
