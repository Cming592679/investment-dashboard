# Thesis 卡 — 维护规则

> 依据：INVESTMENT_RULEBOOK_DRAFT.md v1.0（§10.2 Thesis / §10.3 Edge）。
> 这是系统的"信念层"：人写、人维护；AI 只能草稿，人定稿。

## 每板块一张卡，固定结构

1. Thesis（我为什么相信，一句话）
2. 市场为什么可能错（错误定价来源）
3. 核心驱动（机制链）
4. Edge（可证伪机制）——必须可机械检查
5. 支持证据 / 反驳证据（引用领先指标与事件）
6. 我最可能错在哪（反方假设）
7. 改变观点的条件（证伪条件 / 部分证伪信号）
8. 对应标的与主题
9. 失效后仓位处理
10. 当前 Signal 状态（引用 config 中的领先指标，不复制数值以免过时）
11. 建议档位（Explore/Watch/Verify/Core，由用户确认）

## 规则

- 证伪条件必须写成"可机械检查"的语句（如"DRAM 合约价连续 2 季涨幅 <3%"）。
- 档位只随验证/证伪变化，不随价格变化。
- 新板块没有 Thesis 卡不得进入任何档位。
