# Technical Check — 投资仪表盘全指标入场检查

基于仪表盘 API 数据，强制走完所有技术指标的入场条件检查。

## 触发

- 用户问"某某板块现在能买吗"
- 用户问"某某板块现在该加仓/减仓/清仓吗"
- 任何需要给出具体操作建议的场景

## 工作流

### Step 1 · 拉取全量数据

```
curl -s "http://localhost:5000/api/fund/<fund_id>?refresh=1"
```

解析返回 JSON，提取：
- `assessment`: 三层信号（Layer1/2/3）
- `stocks`: 每只持仓股的价格、RSI、indicators（MACD/布林/KDJ/均线）
- `indices`: 参考指数
- `fund_return_pct`: 当日基金回报

### Step 2 · 五项入场检查（按权重排序）

逐只检查每只持仓股，统计通过比例。**只要输出结论必须带统计数据，不允许"感觉好像可以"。**

| # | 检查项 | 判据 | 如何判断 |
|---|--------|------|----------|
| 1 | **MACD 趋势** | 金叉或柱状图转正 | `indicators.macd.signal == "golden_cross"` 或 `histogram > 0` |
| 2 | **布林带位置** | 触下轨（恐慌耗尽） | `indicators.bollinger.position == "below_lower"` |
| 3 | **KDJ 拐点** | 超卖区金叉 | `indicators.kdj.status == "oversold"` 且 K > D |
| 4 | **RSI 超卖** | < 超卖阈值 | `rsi <= fund.exit_thresholds.rsi_oversold`（A股25，美股30）|
| 5 | **MA50 趋势** | 至少 1/3 在线 | `above_ma50 == true` 的比例 >= 1/3 |

### Step 3 · 三层上下文

从 `assessment.details` 中提取：

```
Layer1: 暴跌预警 / RSI超卖 / MA50破位
Layer2: 瓶颈突破(利好/利空) / 联动降级
Layer3: 周期锚点 → 超卖=机会/观望/警惕
```

### Step 4 · 综合判定

**必须列出完整的检查表，不允许跳过任何一项。**

判定规则：

```
5/5 通过 → 🟢 入场信号齐备，可按目标仓位执行
3-4/5 通过 → 🟡 多数信号就位，可轻仓试探（目标仓位1/3）
1-2/5 通过 → 🟠 信号不足，标记关注，等更多信号
0/5 通过 → 🔴 尚未见底，继续观望
```

**Layer3 权重调节**：
- 周期 early + oversold → 可放宽到 2/5 即可轻仓（早期超跌容错率高）
- 周期 mid-to-late + oversold → 必须 4/5 才动手（中后期容错率低）

### Step 5 · 输出格式

```markdown
## <板块名>（<fund_id>）入场检查

### 五项信号灯
| 信号 | 状态 | 详情 |
|------|------|------|
| MACD 趋势 | ❌ | 0/5 金叉，全部死叉中 |
| 布林带触下轨 | ❌ | 0/5 触下轨 |
| KDJ 超卖金叉 | ❌ | 2/5 K<20 但无金叉 |
| RSI 超卖 | ✅ | 4/5 超卖（最低 RSI 6.1）|
| MA50 趋势 | ❌ | 0/5 在线 |

**通过: 1/5 → 🟠 信号不足**

### 三层上下文
- 🎯 Layer3: 萌芽期 → 超卖=机会
- 📋 Layer2: 领先4/4向好
- ⚡ Layer1: RSI深度超卖但 MACD 全死叉

### 结论
基本面没问题，但技术面入场信号只亮了 1/5 盏。MACD 全死叉 + 布林未触下轨 = 趋势未反转。**不建议现在入场，等 MACD 金叉或 KDJ 超卖金叉出现。**

### 等待信号
- MACD 金叉（至少 2/5 只出现）
- 价格触及布林下轨
- KDJ 在超卖区金叉
```

## 约束

- **禁止跳过任何检查项**——五盏灯每盏都必须亮出结果
- **禁止在未列出五盏灯的情况下给出操作建议**
- **统计数字必须来自 API 数据，禁止凭感觉**
